## 2025-05-23 - Real World Data in Simulations
**Learning:** Users can have a strong preference for "real" functionality even in simulated environments. While we cannot implement backend network tunnels in a browser sandbox, we can ground the experience by using real data where possible (like IP fetching).
**Action:** When designing "simulations", always look for opportunities to fetch real metadata (IP, Location, ISP) to bridge the gap between demo and reality. This increases immersion significantly.
